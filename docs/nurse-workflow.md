# Nurse Workflow — Improvements

Proposed step-by-step ordering for the nurse-facing flow, with explicit system pages/screens called out where the nurse needs to confirm or be shown something.

1. **Nurse manually checks if the ID/personal detail inputted is correct**
   - This check has to be indicated in the system as done.
   - *Page explicitly for this.*

2.1. **Once the ID check is correct, the system tells the nurse what forms need to be filled out — only if TPA is involved** — and automatically fills in the electronic forms if the patient submitted their documents previously.
   - *Page explicitly for this.*

2.2. If the preregistration indicated the patient is here for a checkup, the nurse hands over the 2 forms to the patient to fill in first.

2.3. In the meantime (during 2.1 and 2.2), if one of the documents is from a TPA, the nurse refers to the forms indicated by the system and physically fills up the necessary forms on paper.

3.1. **Once form-filling is done, the system notifies and shows the nurse whether the e-forms filled in are correct.** If the nurse approves, move on to the next step.
   - *Page explicitly for this.*

3.3. Once the nurse is done filling up the physical form, they check if the system is correct.

4.1. **The system checks CHAS + corporate insurance eligibility and returns the package.** If the nurse approves, move on to the next step.
   - *Page explicitly for this.*

4.3. The nurse checks if the system is correct.

5.1. **The system uses all inputted data to calculate the billing code and uncovered cost.** If the nurse approves, assign the queue number.
   - *Page explicitly for this.*

5.3. The nurse checks if the information is correct. If it is, the nurse approves.

6.1. **The system shows the queue number, billing code, and uncovered cost on the final screen.**
   - *Page explicitly for this.*

6.2. By this point, the patient should be done filling up the 2 physical forms. The patient gives them back to the nurse, is told about the uncovered cost, and receives the queue number.

6.3. The nurse receives the 2 forms and reads the final screen.
